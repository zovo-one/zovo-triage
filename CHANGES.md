# Fork changes

Zovo Triage 1.0.0 is a differentiated fork of Refined GitHub. The upstream
interface-refinement core is retained under its MIT licence and copyright notice.

This fork adds:

- a popup notification board with repository/reason filters, mark-done, and snooze;
- keyboard-first issue and pull-request bulk selection, labelling, and closing;
- five pinned saved-search shortcuts stored locally;
- generated/lockfile auto-collapse and an ignore-whitespace diff control;
- a separately namespaced visual layer, original icon set, and supporter licence flow.

The product packaging, popup, fork-specific feature layer, licence verification,
and artwork are original modifications. No upstream copyright notice was removed.
